XG5 turns a jailbroken PS5 into a game store. Open the app, browse a live catalog,
download with a native multi-connection engine, install and play — no PC in the loop.

## ✨ Features

- 🛒 **A real store on the console** — popular now, new releases, genres, search, filters and favorites
- ⬇️ **Serious downloader** — 64 parallel connections, adaptive range sizing, and pause/resume that actually resumes
- 📦 **Install and play** — PS5 game images mount straight from the app, PS4 PKGs install with one press
- 🧹 **Zero cleanup** — archives extract themselves and leftovers are removed after install
- 🌍 **Your language** — 14 languages with full right-to-left support: فارسی · العربية · اردو
- 🎮 **Console-native UI** — built for the gamepad, in the store style you know

## 📥 Install

1. A jailbroken PS5 with homebrew enabled.
2. Grab the latest **XG5** zip — see the Telegram channel.
3. Install it the way your exploit host installs homebrew titles, then open **XG5** from the home screen.
