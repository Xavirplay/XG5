XG5 turns P5 into a game store. Open the app, browse a live catalog,
download with a native multi-connection engine, install and play — no PC in the loop.

## ✨ Features

- 🛒 **A real store on the console** — popular now, new releases, genres, search, filters and favorites
- ⬇️ **downloader** — 64 parallel connections, adaptive range sizing
- 📦 **Install and play** — PS5 game images mount straight from the app, PS4 PKGs install with one press
- 🧹 **Zero cleanup** — archives extract themselves and leftovers are removed after install
- 🎮 **Console-native UI** — built for the gamepad, in the store style you know

## 📥 Install
put the file in homebrew folder like any other  games
